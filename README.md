## 📌 Project Overview
This project applies four core ethical principles from Indian Philosophy to modern Machine Learning and Data Science governance:
1. **Satya (सत्य - Truthfulness):** Accuracy, Calibration & Label Integrity.
2. **Ahimsa (अहिंसा - Non-Harm):** Algorithmic Injury Mitigation & Disparate Impact (80% Rule).
3. **Dharma (धर्म - Duty & Responsibility):** Explainability (Feature Attribution) & Model Governance Cards.
4. **Justice / Nyāya (न्याय - Fairness):** Demographic Parity & Equal Opportunity.

---

## 📂 Included Real-World Benchmark Datasets
- `data/real_world_german_credit.csv`: 1,000 real banking clients from UCI Machine Learning Repository (Credit risk & loan approval).
- `data/real_world_adult_census_recruitment.csv`: 2,299 real workforce candidate profiles from UCI Adult Census dataset.
- `data/recruitment_hiring_data.csv`: Controlled recruitment dataset demonstrating algorithmic bias and disparate impact.
- **Custom CSV Upload:** Support for uploading any custom dataset.

## 🚀 How to Run the Application

1. Open PowerShell or Command Prompt in this folder:
   ```bash
   cd C:\Users\HP\.gemini\antigravity\scratch\nitiai_project
   ```

2. Activate the virtual environment:
   ```bash
   .\.venv\Scripts\activate
   ```

3. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
   *(Or simply double-click `run_app.bat`)*

4. Open your browser at `http://localhost:8501`.
